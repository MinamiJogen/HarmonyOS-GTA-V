# v0.8.0

面向 **HarmonyOS API 26 / ARM64** 的 GTA V WebAssembly 运行环境，提供 Vulkan 渲染、OHAudio 音频、触屏与键鼠输入，以及资源导入界面。

## 下载与安装

[v0.8.0 Release](https://github.com/MinamiJogen/HarmonyOS-GTA-V/releases/tag/v0.8.0) 提供 `HarmonyOS-GTA-V-v0.8.0.hap`。该安装包**未签名**，包含游戏运行时与 ARM64 AOT；安装前需使用自己的 DevEco 开发者配置签名，并安装到签名 profile 允许的设备。

运行还需自行准备并导入与 AOT 匹配的游戏数据和着色器。普通 PC 版安装目录不能直接替代这些资源。仓库不包含游戏原始 Wasm、游戏数据、游戏着色器、开发者证书、私钥或设备 profile。

源码与构建脚本见[源码仓库](https://github.com/MinamiJogen/HarmonyOS-GTA-V/tree/main)，签名与安装步骤见[中文编译说明](../BUILD.zh-CN.md)。

## 资源导入

1. 将自己准备的兼容资源 ZIP 复制到设备，无需手动解压。
2. 打开应用，点击“选择游戏 ZIP”，或使用“打开下载目录”找到资源包。
3. 等待导入与校验完成，首页显示资源就绪后点击“开始游戏”。

支持 ZIP / ZIP64、导入进度与取消操作，也支持系统文件管理中的 ZIP 打开入口。应用仅从 ZIP 导入数据和着色器，不加载其中的 AOT、HAP 或 Wasm。当前接受的资源构建为 `8b0b5899ed`，需与安装包内的 AOT 匹配。

建议设备预留至少 35 GB 可用空间。导入会保留原 ZIP，资源替换前需完成校验；游戏运行期间不能替换资源。

## 自行构建

准备自己的兼容游戏文件与开发环境后，在源码根目录执行：

```sh
bash tools/build_game.sh --check
bash tools/build_game.sh --zip /absolute/path/your-game.zip
```

也可使用 `--wasm /absolute/path/game.wasm` 指定已有程序，或双击 `build.command`。默认生成未签名 HAP；配置自己的签名后可添加 `--signed`。环境与分阶段构建方法见[中文编译说明](../BUILD.zh-CN.md)。

## 运行限制

空间超分需设备支持；改变窗口比例或折叠状态后需重启应用。性能随设备、画质和场景变化，本版本不保证在所有 API 26 设备上具有相同表现。
