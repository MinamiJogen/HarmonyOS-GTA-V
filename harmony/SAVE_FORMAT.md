# 存档与 ZIP 导入

首页提供“开始新游戏”“加载存档”和“开始 Demo”。新游戏进入剧情模式，并通过原引擎的 `-noautoload` 禁止启动时自动读旧档；不会清空已有手动存档。加载列表对应剧情保存目录，Demo 使用独立沙盒目录。

## ZIP 内容

最简单的方式是把进度文件直接压成 ZIP，例如：

```text
my-saves.zip
├── SGTA50000
├── SGTA50001
└── SGTA50015
```

支持普通进度槽 `SGTA50000` 至 `SGTA50015`，其中 `SGTA50015` 是自动保存槽。可附带对应 `.bak` 文件，但 ZIP 不能只有 `.bak`。槽位命名也与 [GTASnP 的格式说明](https://gtasnp.com/help/games/gtav)一致；本移植版实际路径以原始 Wasm 的文件系统调用为准。

也支持以下外层目录：

- `Default/SGTA50000`
- `Profiles/<单个账号 ID>/SGTA50000`
- `Rockstar Games/GTA V/Profiles/<单个账号 ID>/SGTA50000`
- `saves/userdata/Documents/Rockstar Games/GTA V/Default/SGTA50000`
- 自家 Demo 备份可保留 `saves/sandbox/Documents/Rockstar Games/GTA V/Default/` 路径，仍留在独立演示目录。

外部 PC 目录会映射到当前引擎的 `Default` 目录；不能在一个 ZIP 中混合多个账号。`settings.xml`、平台元数据不会覆盖当前画质设置；程序、游戏资源及未知配置文件不作为进度导入。请只压缩需要的存档文件。

支持单卷、未加密、非 ZIP64 的 Store/Deflate ZIP。压缩包及总解压量各不超过 64 MiB、单文件不超过 16 MiB、目录条目不超过 512。导入会校验 ZIP 目录、文件长度、CRC 和路径，拒绝越界路径及符号链接。

## 兼容性与备份

当前原引擎的进度文件外层头至少为 264 字节，头版本为大端整数 1。文件名或外层头正确，仍不能保证内部游戏版本、压缩数据和剧情状态兼容；最终由原引擎解密、解析并反序列化确认。不要把别的平台或 Enhanced 存档仅改名后视为兼容。

同名主档或 `.bak` 在替换前会备份到应用私有的 `save-backups/import-…/`，其中 `plan.txt` 记录原位置，`original-N` 保存原始字节。函数内导入失败会尝试回滚已替换文件；若因 I/O 错误未能完整回滚，将报告警告和原档备份位置，请保留该备份。每个文件单独原子替换；多档导入过程中强杀或断电后的自动恢复尚未实现，不能把它视为整个 ZIP 的跨进程原子事务。

用户数据与 `game/` 资源目录分开。重新导入游戏资源不会删除存档；卸载或清除应用数据前应自行保留备份。不同包名的应用不自动共享存档。

## 游戏内操作

点击覆盖层的“菜单按键”可切换为方向键、确认、返回以及 Q/E 标签切换。原游戏中按 Esc → GAME → Load Game 查看和加载同一目录的进度。手动保存仍使用原游戏手机的快速保存或安全屋保存界面，是否可保存由原剧情状态决定；任务、过场动画等状态可能禁止保存。自动保存也使用同一文件系统，不需要另行导出网页存储。

## 加载机制

原引擎没有已确认的“指定槽位”命令行参数，默认会从存档标题的日期选择最新档。本地选择器会在启动读档期间仅向原引擎暴露所选真实档，不改写文件内容、时间或其他存档。收到原引擎明确的反序列化成功或失败结果后，恢复完整列表，供游戏内菜单继续保存和加载。若启动阶段未找到可读候选、读档报错、运行被停止，或 5 分钟内没有成功确认，会明确提示失败并释放过滤；不会把出现游戏画面当成读档成功。

格式、路径和原接口取证见 `evidence/research/original-game-save-interface-20261019.json`。具体设备验收以对应实测记录为准；编译、ZIP 合同测试不等于已完成游戏内保存和恢复验证。

原游戏内手动加载完成读取后，会通过一次性启动参数重启应用进程，再由新进程加载刚选中的剧情档。这样避开原引擎在本地移植环境中重建进程级配置时的等待；启动参数不写入画质配置，也不更改进度内容。游戏内确认读档后将直接继续加载，不需要再次回首页选择。最终仍以新进程原引擎的反序列化成功为准。

## 本次真机验证

2026-10-19 至 20 日在 MatePad Pro Max / API 26 实测：首页无存档提示、三种启动入口、系统文档选择器 ZIP 导入、所选剧情档反序列化、选择旧日期档而非自动选最新档，以及原手机快速保存创建新槽均已通过。手动保存实写 `SGTA50002` 与 `.bak`，原引擎报告 `ManualSave operation MEM_CARD_COMPLETE`。原游戏确认读档后自动重启接力也已通过，最终恢复了手动保存的同一槽位。六个测试文件均核对 SHA 后移到独立归档，正式存档列表恢复为测试前状态；原设置与画质配置逐字节一致。详细证据在 `evidence/device/matepad-pro-max/save-management-20261019/acceptance.json`。公开 PC 旧版样本只作为单个兼容性测试，不代表支持所有 PC、主机或 Enhanced 存档。
